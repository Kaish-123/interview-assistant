# TechyEra Website

A modern, high-converting website for TechyEra - Proxy Interview Support for Data Engineering roles.

## 🚀 Features

- **Modern Dark Theme** - Professional tech aesthetic with cyan/teal accents
- **Fully Responsive** - Works on all devices (desktop, tablet, mobile)
- **Smooth Animations** - Scroll animations and micro-interactions
- **WhatsApp Integration** - Floating chat button and multiple CTAs
- **SEO Optimized** - Proper meta tags and semantic HTML
- **Fast Loading** - Minimal dependencies, optimized assets

## 📁 Project Structure

```
techyera-website/
├── index.html      # Main HTML file with all sections
├── styles.css      # Complete CSS with design system
├── script.js       # JavaScript for interactivity
└── README.md       # This file
```

## 🎯 Sections Included

1. **Hero** - Eye-catching headline with tech stack display
2. **Trusted By** - Scrolling company logos
3. **Services** - 6 service cards with features
4. **How It Works** - 4-step process timeline
5. **Why Choose Us** - Features list with stats card

7. **Testimonials** - Customer success stories
8. **FAQ** - Accordion-style questions
9. **Final CTA** - Prominent WhatsApp conversion section
10. **Footer** - Links, contact info, social media

## ⚙️ Customization

### Update WhatsApp Number

Replace `YOUR_WHATSAPP_NUMBER` in `index.html` with your actual number:
```
wa.me/YOUR_WHATSAPP_NUMBER → wa.me/1234567890
```

### Change Pricing

Edit the pricing cards in the `#pricing` section of `index.html`.

### Update Testimonials

Modify the testimonial cards in the `#testimonials` section.

### Social Media Links

Update the `href` attributes in the footer social links section.

## 🌐 Deployment Options

### Option 1: Netlify (Recommended - Free)

1. Go to [netlify.com](https://netlify.com)
2. Drag and drop the `techyera-website` folder
3. Your site is live!

### Option 2: Vercel (Free)

1. Go to [vercel.com](https://vercel.com)
2. Connect your GitHub repo or drag-drop the folder
3. Deploy!

### Option 3: GitHub Pages (Free)

1. Create a GitHub repository
2. Upload all files
3. Go to Settings → Pages → Select main branch
4. Your site will be at `username.github.io/repo-name`

### Option 4: Traditional Hosting

Upload all files to your hosting provider via FTP or file manager.

## 🎨 Color Customization

Edit CSS variables in `styles.css`:

```css
:root {
    --accent-primary: #00d4aa;      /* Main accent color */
    --accent-secondary: #00f5c4;    /* Secondary accent */
    --bg-primary: #0a0a0f;          /* Main background */
    --bg-secondary: #111118;        /* Section backgrounds */
    --bg-card: #14141c;             /* Card backgrounds */
}
```
